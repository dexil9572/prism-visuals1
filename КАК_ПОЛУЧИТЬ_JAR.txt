В этом архиве — полный исходный код мода Prism Visuals для Minecraft 26.2 (Fabric).

=== САМЫЙ ПРОСТОЙ СПОСОБ — ГОТОВЫЙ JAR ===

1. Открой страницу репозитория на GitHub.
2. Справа выбери вкладку "Releases" и скачай prism-visuals-1.1.0.jar
   из последнего релиза "Prism Visuals 1.0.1 — Minecraft 26.2 (Fabric)".
   (Если релиза ещё нет — вкладка Actions -> последняя удачная сборка
   "Build Prism Visuals" -> внизу блок Artifacts -> prism-visuals-jar.)
3. Этот jar — уже собранный мод, больше ничего собирать не надо.

=== ПЕРЕД ИГРОЙ ПОСТАВЬ ===

- Minecraft 26.2 + Fabric Loader (https://fabricmc.net/use/installer/)
- Fabric API для 26.2 (https://modrinth.com/mod/fabric-api) — тоже в папку mods
- Java 25 (нужна самой игре 26.x)

Скачанный prism-visuals-1.1.0.jar положи в папку .minecraft/mods рядом с Fabric API.

=== СПОСОБ НА СВОЁМ КОМПЬЮТЕРЕ (кто хочет собирать сам) ===

Понадобится JDK 25: https://adoptium.net/temurin/releases/?version=25
и Gradle 9.7.1: https://gradle.org/install/
Потом в папке проекта:

  gradle wrapper --gradle-version 9.7.1
  gradlew build          (на Windows: gradlew.bat build)

Готовый JAR появится в папке build/libs/.

=== ЕСЛИ СОБИРАЕШЬ В ОБЛАКЕ (GitHub Actions) ===

1. Залей все файлы проекта (включая скрытую папку .github) в свой репозиторий.
2. Вкладка Actions -> "Build Prism Visuals" -> Run workflow.
3. Через 3-6 минут готовый jar будет в Artifacts и в Releases.
